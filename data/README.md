# data/

Tempat berkas seed atau contoh data kelompokmu (CSV/JSON kecil).

Aturan:

- **Data contoh saja.** Jangan pernah menaruh data pribadi orang sungguhan di sini —
  nama, NIK, nomor telepon, alamat, rekam medis. Repo ini publik.
- Kalau domainmu memakai data orang, **buat data sintetis**. Itu bukan kecurangan; itu praktik
  standar, dan lebih aman.
- Berkas besar (>5 MB) tidak perlu di-commit. Kecilkan dulu.
